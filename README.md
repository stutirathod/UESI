# Overview

The UESI Website Enhancement Project is a web-based platform developed to improve the existing UESI website by adding modern and interactive features. The system provides functionalities such as online courses, article management, program updates, online charity donations, and feedback management to create a better user experience and support UESI’s mission effectively.

---

# Tech Stack

## Frontend
- React.js (v18)
- HTML5
- CSS3
- JavaScript (ES2023)

## Backend
- Node.js (v20)
- Express.js

## Database
- MongoDB

---

# Requirements

Before running this project, make sure the following software is installed on your system:

- Node.js (v20 or later)
- npm (Node Package Manager)
- MongoDB
- Git
- Code Editor (Recommended: VS Code)

---

# Installation

## Clone the Repository

```bash
git clone https://github.com/stutirathod/UESI.git
```

## Navigate to Project Directory

```bash
cd UESI
```

## Install Dependencies

```bash
npm install
```

---

# Running the App

## Start the Development Server

```bash
npm start
```

After starting the server, open your browser and visit:

```text
http://localhost:3000
``
